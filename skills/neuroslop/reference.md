# Каталог признаков нейрослопа в русском тексте

Порядок разделов: сначала то, что выдаёт Claude, потом общие признаки LLM. В каждом пункте: как выглядит → как править. «→ ∅» значит «удалить без замены».

## 1. Почерк Claude

Claude думает по-английски и пишет по-русски калькой. Тики стабильные, их легко узнать.

| Признак | Пример | Правка |
|---|---|---|
| Псевдорасщепление (What makes X is Y) | «То, что делает баг коварным, — это то, что он плавающий» | «Баг коварный: он плавающий» |
| «Всё, что нужно, — это…» | «Всё, что нужно сделать, — это перезапустить под» | «Достаточно перезапустить под» |
| Анонс с двоеточием (Here's what/how) | «Вот что происходит:», «Вот в чём штука:», «Суть в том, что» | → ∅, сразу суть |
| Ярлык-лид | «**Коротко:**», «Итог:», «Важный нюанс:», «Ключевой момент здесь —», «Что я бы сделал:» | → ∅ |
| Контраст ради контраста | «Проблема не в Redis, а в инвалидации», «Это не баг, а фича», «Это не серебряная пуля, но…» | «Ключи не инвалидируются» — назови то, что есть |
| Оценка реплики | «Хороший вопрос — и…», «Отличная идея», «Вы абсолютно правы» | → ∅ |
| Ложная доверительность (honestly) | «Честно говоря,», «Если честно,» | → ∅ |
| Усилители-пустышки (genuinely, really, actually) | «действительно знает», «по-настоящему», «на самом деле», «по сути», «буквально», «ровно то» | → ∅ |
| Хеджи (pretty, quite, fairly) | «довольно типичная», «достаточно сложно», «в целом» | → ∅ или конкретная мера |
| Фирменные слова | «несущий» (load-bearing), «ловушка», «подвох», «тонкий момент», «острый» (sharp), «приземлить» (land) | «главный», «на нём всё держится», «ошибка» |
| Хвост «, что делает его…» (making it) | «Баг плавающий, что делает его сложным для воспроизведения» | «Баг плавающий, его трудно воспроизвести» |
| «Это» как подлежащее-отсылка | «Это даёт нам гарантию…», «Это означает, что…», «Это позволяет…» | «Поэтому…», «Значит,…», или слей с прошлым предложением |
| «Есть N причин, почему» | «Есть три причины, почему это важно:» | «Причин три.» или сразу перечисли без анонса |
| Список из трёх с жирными лидами | «- **Консистентность.** …\n- **Масштабируемость.** …» | связный абзац; список только для шагов и однородных пунктов |
| Тире-пауза перед «и/а/но» | «Данные устарели — и это подрывает доверие» | «Данные устарели. Пользователь перестаёт верить» |
| Предложение помощи в конце | «Если хотите, могу…», «Хочешь, я…?», «Дайте знать» | → ∅. Текст кончается последней мыслью |
| «Я бы» (I'd) как вводная | «Я бы начал с…» | «Начните с…» / «Сначала…» |

## 2. Тире

Норма (оставь):
- подлежащее и сказуемое — существительные без связки: «Стенды — виртуальные машины»;
- термин — определение в списке или справочнике: «**Terraform** — создаёт VM»;
- пропущенный член: «Мне — чай, ему — кофе»; диапазон: «2–4 минуты».

Слоп (правь):
- тире вместо двоеточия, запятой или точки, чтобы «выдохнуть»: «Результат — рост метрик»;
- «X — это Y», когда без «это» понятно, особенно несколько раз подряд;
- тире-пауза перед «и/а/но»: «…— и это важно»;
- «Если X — Y»: «Если нужно сэкономить — выключите стенд» → «Чтобы сэкономить, выключите стенд»;
- пара тире-вставок вместо скобок или запятых;
- плотность: больше 5 тире на 1000 слов прозы — повод перечитать каждое.

## 3. Обороты

- **Хвостовое деепричастие** — главный признак LLM (калька `, ensuring/highlighting/making…`). «…оптимизирует расходы, обеспечивая вовлечённость» → «…оптимизирует расходы. Вовлечённость при этом не падает».
- **Два деепричастия в одном предложении**: «Работая из дома, специалисты экономят время, получая возможность…» → «Дома не надо ездить в офис. Освободившееся время уходит на задачи».
- **Постпозитивный причастный оборот** с «являющийся/обладающий/позволяющий/обеспечивающий/представляющий собой»: «Коммуникация, являющаяся основой работы» → «Без общения команда не работает».
- **Цепочка «который»** — та же болезнь, только без причастий. Больше одного «который» в предложении → дели.
- Одиночное причастие перед существительным («защищённая ветка», «устаревшие данные») — норма.

## 4. Порядок слов и синтаксис

Русский ставит новое в конец, известное в начало (тема → рема). Английский порядок «подлежащее–сказуемое–дополнение–обстоятельство» выдаёт перевод.

| Калька | По-русски |
|---|---|
| «Мы выпустили новую версию вчера» | «Вчера мы выпустили новую версию» |
| «Я также добавил тесты» (also) | «Ещё я добавил тесты» / «Тесты тоже добавил» |
| «Он открыл свой ноутбук и проверил свою почту» | «Открыл ноутбук, проверил почту» — притяжательные и подлежащие опускай |
| «Баг был исправлен командой» | «Команда исправила баг» |
| «Когда учитель спешит, это приводит к…» | «Из-за спешки учителя…» / «Если учитель спешит, …» |
| «Что касается производительности, то…» | «По производительности…» / начни с сути |
| «Это то, что нам нужно» | «Это нам и нужно» |
| «Повышение уровня качества обслуживания клиентов» | «Клиентов обслуживают лучше» — цепочку родительных падежей замени глаголом |
| «Причина проста:», «Проблема в том, что» | можно, но не в каждом абзаце |
| Номинативные обрывки: «Два года. Без операций. Только контроль.» | связное предложение |
| Риторический вопрос-ответ: «Результат? Рост.» / «Почему? Потому что…» | утверждение |

## 5. Кальки и англицизмы

| Калька | Источник | По-русски |
|---|---|---|
| имеет смысл | makes sense | логично, разумно, стоит |
| в конце дня | at the end of the day | в итоге, в конечном счёте, → ∅ |
| делать разницу | make a difference | влиять, менять дело |
| адресовать проблему | address | решать, разбираться, заняться |
| на ежедневной основе | on a daily basis | каждый день |
| в терминах X | in terms of | по части X, если говорить об X |
| в контексте X | in the context of | в X, для X, когда речь об X |
| играет ключевую роль | plays a key role | влияет, решает, без него не… |
| это про X / это не про X | it's about | речь о X, главное — X |
| фокусироваться на | focus on | заниматься, сосредоточиться |
| вызов (не про функцию) | challenge | трудность, задача |
| ключевой, критически важный | key, critical | главный, основной, без этого не работает |
| звучит как / звучит разумно | sounds like | похоже, разумно |
| иметь дело с | deal with | работать с, столкнуться |
| обеспечить, предоставить, позволить | ensure, provide, allow | дать, сделать, можно |
| бесшовный, робастный, импакт, инсайт, драйвить, экосистема, ландшафт | seamless, robust… | плавный, надёжный, влияние, вывод, двигать; → ∅ |
| раскрыть потенциал, новые горизонты, на новый уровень, мощный инструмент, меняет правила игры, серебряная пуля | маркетинг | конкретный результат или → ∅ |
| погрузимся, давайте разберёмся, исследуем | let's dive in, explore | → ∅ |

Профессиональный жаргон аудитории — не слоп: в техдоке «под», «деплой», «MR», «инстанс», «чарт», «пушить» остаются. Правь кальки синтаксиса и модные слова, а не термины.

Обратная ошибка — обрусить термин в замене. Глагол или существительное для технического действия бери из самого текста: если там «рендерит», в замене «отрендерил», а не «отрисовал».

| Термин | Ложная замена |
|---|---|
| рендерить, отрендерить (render шаблонов, манифестов) | отрисовать |
| коммит, закоммитить | фиксация, зафиксировать |
| мерж, влить | слияние, слить |
| MR | запрос на слияние |
| под | модуль, контейнер |
| тег (образа) | метка |
| бандл | пакет, сборка |

## 6. Канцелярит

- «является» → тире, «это» или перестройка: «Redis является кэшем» → «Redis — кэш».
- «данный» → «этот».
- Отглагольные существительные вместо глаголов: «осуществить установку» → «установить»; «производить настройку» → «настроить»; «обеспечение доступности» → «чтобы сервис был доступен».
- Предлоги: в рамках, в целях, с целью, в связи с, посредством, в качестве, в случае если, имеет место → «в», «для», «чтобы», «из-за», «через», «если», «есть».
- Размытое: определённый, соответствующий, ряд, целый ряд, комплексный → конкретика или → ∅.
- В юридическом, научном и официальном тексте канцелярит — норма жанра. Там правь только то, что мешает понять.

## 7. Риторика и композиция

- **Зачины**: «В современном мире», «В эпоху», «На сегодняшний день», «Сегодня мы поговорим» → начни с факта.
- **Подводки**: «Стоит отметить», «Важно понимать», «Нельзя не отметить», «Можно с уверенностью сказать» → → ∅.
- **Формульные выводы**: «Подводя итог», «Таким образом», «В заключение» → → ∅ или вывод без ярлыка.
- **Пары-шаблоны**: «не только…, но и», «как для X, так и для Y» → «X и Y», если пара не несёт противопоставления.
- **Правило трёх**: тройки однородных («быстро, надёжно и удобно»), карусель синонимов → оставь одно точное слово.
- **Раздувание значимости**: «играет важную роль», «трудно переоценить», «открывает возможности».
- **Ровный ритм**: все предложения одной длины, все абзацы по 3 предложения. Живой текст рваный.
- **Схема «тезис, три плюса, но есть минусы, итог»**: перестрой под задачу читателя.
- **Пустота**: ни цифры, ни примера, ни имени. Конкретику не выдумывай. Отметь, где автору её добавить.
- **Оформление**: жирный посреди фразы, заголовки в тексте на 200 слов, эмодзи-маркеры, списки там, где нужен абзац.
